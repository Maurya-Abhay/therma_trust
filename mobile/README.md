# 📱 ThermaTrust Mobile App

**Framework:** Expo + React Native  
**Platform:** Android & iOS  
**Backend:** Express.js + MongoDB  
**Build System:** Expo Application Services (EAS)

ThermaTrust Mobile is a role-based mobile application for Admin, Facility Manager, Contractor Manager and Technician users.
